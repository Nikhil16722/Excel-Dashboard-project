## 📖 Project Overview
This project is a comprehensive data analysis and visualization exercise using Microsoft Excel. It demonstrates the complete workflow from processing a raw dataset to creating an interactive and informative dashboard, specifically focusing on the Vrinda Store data.

## ⚙️ Workflow & Steps

### 1. Dataset Collection
* Gathered the raw dataset for Vrinda Store.
* Imported the raw data into Excel for preliminary review and formatting.

### 2. Data Cleaning
* Checked for missing or null values and handled them appropriately.
* Removed duplicate entries to ensure data integrity.
* Standardized text formats, dates, and numerical values for consistency.

### 3. Data Processing & Lookups
* Used advanced Excel functions to process and enrich the data.
* Implemented **VLOOKUP / XLOOKUP** to merge data from different tables and map relevant information.
* Created calculated columns to derive new metrics necessary for deeper analysis.

### 4. Data Visualization & Dashboard Creation
* Built **Pivot Tables** to summarize the cleaned data and extract key insights.
* Designed various charts (e.g., Bar Charts, Line Graphs, Pie Charts) to represent sales trends, demographics, and other critical metrics visually.
* Assembled the charts into a cohesive **Interactive Dashboard**.
* Added **Slicers** to allow dynamic filtering and interactive exploration of the data.

## 🛠️ Tools & Features Used
* **Tool:** Microsoft Excel
* **Functions:** VLOOKUP / XLOOKUP, IF, SUMIFS, COUNTIFS, etc.
* **Features:** Pivot Tables, Data Validation, Conditional Formatting, Slicers, and interactive Charts.
